# MuNote

[English](README_EN.md)

面向 Android 平板的本地优先手写笔记 + 可搜索扫描 PDF 应用。

MuNote 是一个 clean-room 实现的 Android 项目，目标是把接近 Notein 的手写 / PDF 学习工作流，与扫描教材所需要的 OCR、搜索、跳页和页面组织能力结合起来。默认中文，不要求账号，也不依赖云端笔记服务或付费 OCR API。

## 当前功能

### 书写与编辑

- 原生 Android 触控笔输入，保留高频历史采样
- 压感 + 书写速度共同影响笔宽
- 钢笔、圆珠笔、铅笔、荧光笔
- 笔色 / 粗细收藏，并记住上次使用的笔刷参数
- 笔画橡皮、局部橡皮、多档橡皮大小、清空本页
- 撤销 / 重做
- 套索选择：移动、复制、缩放、删除
- 图形工具：直线、矩形、圆 / 椭圆、箭头、三角形
- 直尺模式：直线自动吸附常用 15° 角度
- 笔模式 / 手模式：无触控笔时可单指书写，双指负责拖动与缩放
- 三指向中间聚合打开整本页面缩略图
- 多次跳转历史，可返回刚才的阅读位置

### 笔记、PDF 与页面管理

- 原生笔记：空白、横线、方格、点阵模板
- 原生笔记支持新增、删除、复制、拖动排序页面
- 原生笔记支持单页更换模板
- 导入 PDF 保留原始文件，不做破坏性改写
- 导入 PDF 同样支持删除、复制、拖动排序页面；通过 MuNote 内部逻辑页顺序实现，原 PDF 字节保持不变
- 页面缩略图、书签、仅看书签页、直接输入页码跳转
- 自动记住上次阅读页
- 应用内双开：同一文档不同页面，或两个不同文档；平板宽屏左右并排，窄屏上下分屏

### 图片、文本与导航

- 插入图片
- 图片可移动、缩放、旋转、裁剪、锁定、删除
- 图片可保存为全局贴纸，在其他文档中重复使用
- 文本框键盘输入，支持移动、缩放、字号调整
- 自定义大纲 / 章节目录
- 页面内跳转链接，可拖到对应文字或笔迹附近
- 页面结构变化时，笔迹、文本、图片、搜索索引、书签、链接与大纲会同步重映射

### 搜索与导出

- 本地简体中文扫描 PDF OCR
- 图片 / 扫描 PDF 关键词搜索、跳页和命中区域高亮
- 本地中文手写识别
- PDF OCR、手写识别、文本框统一搜索
- 大型扫描教材优先 OCR 当前阅读位置附近的页面
- 导出带图片、手写、图形和文本框批注的扁平化 PDF
- 导出显示进度并支持取消

### 资料库与本地数据

- 首页封面缩略图网格
- 默认使用文档第一页作为封面，也可自定义封面
- 长文件名在封面下方自动滚动
- 文件夹、收藏、回收站
- 重命名、恢复、永久删除
- 一键本地完整备份与恢复
- 自动本地备份：应用启动时最多每天一次，保留最近 7 份自动备份
- 备份、文档、图片、贴纸和所有笔记侧车数据都保存在 MuNote 自己的 Android 私有应用目录
- **不会为了备份在 Android 根目录创建 MuNote 文件夹，也不会自动上传云端**
- 中文 / English 双语界面，**首次安装默认中文**

## 发布方式

MuNote 后续安装包统一通过 GitHub Releases 分发，不再把可下载测试 APK 长期存放在 Actions Artifact。

- 候选版本先由 GitHub Actions 使用**永久私有签名**编译，并直接发布为 **Pre-release**。
- 测试通过后，原 Pre-release 直接转为正式 **Release**；不会重新编译，也不会替换已经测试过的 APK。
- 如果候选版本存在问题，不覆盖旧版本，修复后使用新的版本号重新发布。
- 历史 Pre-release 和正式 Release 均保留，不做自动清理。
- 仓库内的 `munote-test.keystore` 仅用于公开测试/debug 包，**不作为正式发布签名**。正式候选版要求 GitHub Secrets 中配置独立的永久私有签名。

## 数据设计

导入 PDF 的原文件与 MuNote 的可编辑数据分开保存。页面删除 / 复制 / 排序对导入 PDF 使用逻辑页映射，因此不会重写原文件。

笔迹、文本、图片、OCR、手写识别索引、内部链接和大纲都以文档 ID 为键单独保存。原生笔记使用稳定的 UUID 文档 ID，因此页面模板 PDF 重新生成时不会让已有批注失效。

## 当前状态

核心功能已经覆盖日常“教材 PDF + 手写笔记”的主要工作流，并持续通过 GitHub Actions 构建。

下一阶段最重要的工作不是继续堆功能，而是真机质量：在目标平板和触控笔上反复测试笔感、掌托误触、长 PDF 性能、分屏布局、图片操作和备份恢复，把交互细节与稳定性磨到可长期使用。
